
## กรอบหน้าเว็บ (shell) — สำคัญที่สุด
หน้าเว็บนี้ใช้ "กรอบสำเร็จรูป" ที่จัดวางเลย์เอาต์ สี ฟอนต์ จังหวะเวลา และการเรนเดอร์สมการให้แล้ว
คุณ **ห้ามเขียน CSS เอง ห้ามสร้าง <div> เลย์เอาต์เอง ห้ามทำ animation เอง ห้ามกำหนดขนาดภาพเอง**
หน้าที่ของคุณคือ "วาดรูป SVG" และ "เขียนคำอธิบายภาษาไทย" เท่านั้น

โครงไฟล์ต้องเป็นแบบนี้เป๊ะ ๆ (คัดลอกไปใช้ได้เลย):

<!DOCTYPE html>
<html lang="th"><head><meta charset="utf-8">
<title>...ชื่อเรื่องสั้น ๆ...</title>
<link rel="stylesheet" href="./lib/katex.min.css">
<link rel="stylesheet" href="./lib/shell.css">
</head><body>
<script src="./lib/katex.min.js"></script>
<script src="./lib/auto-render.min.js"></script>
<script src="./lib/shell.js"></script>
<script>
/* โค้ดของคุณอยู่ตรงนี้ */
</script>
</body></html>

## API ทั้งหมดของ Shell (มีเท่านี้ ห้ามเดาชื่ออื่น)
ทุกฟังก์ชันที่สร้างของ จะคืนค่าเป็น **<g> element เพียงหนึ่งอัน** ที่คุณ appendChild ใส่ได้

Shell.page({title, problem})   → สร้างหัวเรื่อง (คืน <div>, ไม่ต้องใช้ต่อ) เรียกก่อนเสมอ
Shell.canvas()                 → คืน <g> หลักของภาพ กรอบขนาด Shell.W x Shell.H = 960 x 540 เสมอ
Shell.setup('เหตุผลของแนวทาง')  → กล่อง "แนวทาง" ก่อนขั้นที่ 1 (ไม่นับเป็นขั้น) — ใช้บอก
                                 "การตัดสินใจ" ที่มาก่อนทุกขั้น เช่น เลือกแกนตามแนวพื้นเอียงเพราะอะไร
Shell.group('ชื่อกลุ่มขั้นตอน')  → หัวข้อย่อยคั่นในแผงขั้นตอน เช่น 'สร้างแผนภาพวัตถุอิสระ (FBD)'
                                 ใช้ตั้งชื่อ "วิธี" ที่ขั้นตอนกลุ่มนั้นใช้ร่วมกัน
Shell.step('คำอธิบายไทย', {why, uses})
                               → คืน <g> หนึ่งอัน วาดของขั้นนี้ลงไป ของจะค่อย ๆ ปรากฏพร้อมคำอธิบาย
                                 uses: [1,2] เลขขั้นที่ "ตัวเลขในขั้นนี้" เอามาจาก (ระบบทำปุ่มย้อนกลับให้)
                                 why:  เหตุผลสั้น ๆ 1 ประโยค ว่า "ทำไมต้องใช้กฎ/วิธีนี้ตรงนี้"
Shell.label(g, x, y, 'ข้อความ', {role, anchor, until})
                               → คืน <g> ป้ายกำกับ ระบบจะจัดตำแหน่งไม่ให้ทับกันเอง
                                 anchor: [x,y] คือ "จุดที่ป้ายนี้อธิบายถึง" ต้องใส่เสมอ
                                 ถ้าป้ายถูกย้ายไกล ระบบจะลากเส้นโยงกลับไปที่ anchor ให้เอง
                                 until: อายุของป้าย (สำคัญมาก — ช่วยไม่ให้ตัวหนังสือทับกัน)
                                   'step'  = หายไปเมื่อขึ้นขั้นถัดไป (ค่าที่ควรใช้เป็นส่วนใหญ่)
                                   'end'   = อยู่จนจบ (ค่าเริ่มต้น ใช้เฉพาะที่จำเป็นจริง ๆ)
                                   ตัวเลข  = หายไปหลังขั้นที่ระบุ เช่น until: 3
Shell.arrow(g, x1,y1, x2,y2, {role, label, value, unit, until, dash})
                               → คืน <g> ลูกศรพร้อมหัวลูกศรและป้าย **ต้องใช้ฟังก์ชันนี้เสมอ**
                                 ห้ามสร้าง <marker> เอง (เดาค่า orient ผิดบ่อยมาก ลูกศรจะหาย)
                                 value + unit: ค่าจริงที่ลูกศรนี้แทน เช่น value:50, unit:'N'
                                 ระบบจะตรวจว่าความยาวลูกศรตรงกับค่าหรือไม่ (แยกตามแนวนอน/แนวตั้ง)
Shell.answer('คำอธิบายคำตอบ', 'ค่าคำตอบ', {sanity})
                               → กล่องคำตอบสีเขียว
                                 sanity: ประโยคตรวจสอบว่าคำตอบสมเหตุสมผล เช่น เทียบกับกรณีขีดจำกัด
Shell.done()                   → เรียกท้ายสุดครั้งเดียว ระบบจะเรนเดอร์สมการ จัดป้าย และเริ่มเล่น
Shell.C                        → สีที่ใช้ได้ {given, work, answer, note, warn}
Shell.W, Shell.H               → 960, 540

## เมื่อไรใช้ "กระดานเรขาคณิต" (JSXGraph board) แทนการวาด SVG เอง
มีวิธีวาดอยู่ **สองแบบ** เลือกให้ถูกก่อนเริ่มเขียนโค้ด แล้วใช้แบบเดียวทั้งหน้า

**แบบ ก. กระดานเรขาคณิต — Shell.board()**
ใช้เมื่อ "ภาพคือคณิตศาสตร์เอง" คือถ้าวางจุดผิดไปนิดเดียว คำตอบก็ผิดตามทันที เช่น
  • กราฟฟังก์ชัน พาราโบลา เอกซ์โพเนนเชียล ตรีโกณมิติ อนุพันธ์ พื้นที่ใต้กราฟ
  • ภาคตัดกรวย วงกลม วงรี ไฮเพอร์โบลา พาราโบลา
  • การสร้างทางเรขาคณิต เส้นแบ่งครึ่งตั้งฉาก วงกลมล้อมรอบ วงกลมแนบใน เส้นสัมผัส
  • เรขาคณิตวิเคราะห์ ระยะทาง จุดกึ่งกลาง ความชัน จุดตัดของเส้น
  • การแปลงทางเรขาคณิต การสะท้อน การหมุน การเลื่อนขนาน
  • สถิติ แผนภาพกล่อง ฮิสโทแกรม แผนภาพการกระจาย
เหตุผล: JSXGraph คำนวณพิกัดให้เอง คุณจึงไม่ต้อง "กะด้วยสายตา" ซึ่งเป็นที่มาของภาพผิด

**แบบ ข. วาด SVG เองใน Shell.canvas()**
ใช้เมื่อภาพเป็น "ภาพจำลองสถานการณ์" ไม่ใช่ระบบพิกัด เช่น พื้นเอียง คาน วงจรไฟฟ้า
เลนส์และรังสี การชนกันของวัตถุ แผนภาพวัตถุอิสระ ภาพเครื่องกล
เหตุผล: สิ่งเหล่านี้ไม่มีแกน x-y ที่มีความหมาย การวาดเป็นสัญลักษณ์อ่านง่ายกว่ากราฟ

ถ้าลังเล ให้ถามตัวเองว่า "โจทย์นี้มีระบบพิกัดที่ตัวเลขต้องตรงเป๊ะไหม" ถ้าใช่ → แบบ ก.

### API เพิ่มอีก 4 ตัวสำหรับกระดาน (มีเท่านี้)
Shell.board({box, axis, grid, keepaspect})
                → สร้างกระดานและ **คืนค่า board** (ตัวเดียวที่ไม่คืน <g>) เรียกแทน Shell.canvas()
                  box: [xmin, ymax, xmax, ymin] — เป็นแค่ค่าเริ่มต้น ระบบจะจัดกรอบให้พอดีเอง
                  axis: true/false (ค่าเริ่มต้น true)   grid: true/false (ค่าเริ่มต้น false)
                  keepaspect: true เสมอ ยกเว้นกราฟที่สองแกนมีหน่วยต่างกันจริง ๆ
Shell.on(s, el1, el2, ..., {until})
                → ผูกวัตถุบนกระดานเข้ากับขั้นตอน s วัตถุจะปรากฏพร้อมขั้นนั้น
                  **วัตถุที่ไม่ผูกจะโผล่มาตั้งแต่ต้น** ใช้กับสิ่งที่โจทย์ให้มาแต่แรกเท่านั้น
                  until: 'step' = หายเมื่อขึ้นขั้นถัดไป (ใช้กับเส้นช่วยที่ไม่ต้องอยู่ถาวร)
Shell.tag(s, จุดหรือ[x,y], 'ข้อความ', {role, until, dist})
                → ป้ายกำกับจุดบนกระดาน **ใช้ตัวนี้แทน Shell.label เสมอบนหน้าที่มีกระดาน**
                  ใส่ตัววัตถุ JSXGraph ไปตรง ๆ ได้เลย เช่น Shell.tag(s1, A, 'A(-2, 1)')
                  ไม่ต้องแปลงพิกัดเอง ระบบจัดตำแหน่งไม่ให้ทับกันและลากเส้นโยงให้
Shell.px(x, y)  → แปลงพิกัดกระดานเป็นพิกัดกรอบ 960x540 (ใช้เมื่อต้องวาด SVG ทับกระดานเท่านั้น)

### กติกาการใช้กระดาน (ข้อ B1–B6 บังคับ)
B1. **ให้ JSXGraph สร้างเรขาคณิต อย่าคำนวณพิกัดเองแล้วพิมพ์ตัวเลขลงไป**
    ผิด:  var O = b.create('point', [2, 2]);              // คำนวณจุดตัดเองมาก่อน
    ถูก:  var pb1 = b.create('perpendicularbisector', [A, B]);
          var pb2 = b.create('perpendicularbisector', [B, C]);
          var O   = b.create('intersection', [pb1, pb2, 0]);
    จุดที่ "โจทย์ให้มา" เท่านั้นที่พิมพ์ตัวเลขได้ จุดที่ "หาได้จากการสร้าง" ต้องให้ระบบหา
    ชื่อที่ใช้สร้างได้จริง: point, line, segment, circle, polygon, angle, arc, midpoint,
    perpendicular, perpendicularbisector, parallel, bisector, intersection, tangent,
    normal, circumcircle, circumcenter, incircle, incenter, reflection, mirrorpoint,
    glider, functiongraph, curve, conic, ellipse, hyperbola, parabola, semicircle,
    regularpolygon, integral, derivative, riemannsum, slopetriangle, boxplot, text
    ถ้าไม่แน่ใจว่ามีชื่อนั้นจริงไหม ให้ใช้ชื่อที่อยู่ในรายการนี้เท่านั้น
B2. **ข้อความทุกตัวบนกระดานต้องมาจาก Shell.tag หรือ Shell.label เท่านั้น**
    ห้าม b.create('text', ...) ห้ามใส่ {name:'A', withLabel:true} ให้วัตถุใด ๆ
    เหตุผล: ป้ายของ JSXGraph ไม่รู้ว่ามีป้ายอื่นอยู่ตรงไหน จึงทับกันเอง ระบบของเราจัดให้แทน
B3. **สีต้องมาจาก Shell.C เท่านั้น** เช่น {strokeColor: C.work} ห้ามใส่สีอื่นเด็ดขาด
    given = สิ่งที่โจทย์ให้ / work = สิ่งที่สร้างขึ้นระหว่างทาง / answer = คำตอบ
B4. **ผูกวัตถุทุกอันที่ "เกิดขึ้นระหว่างทาง" เข้ากับขั้นด้วย Shell.on**
    ไม่อย่างนั้นภาพจะเสร็จตั้งแต่ยังไม่อธิบาย นักเรียนก็ไม่เห็นลำดับความคิด
    เส้นช่วยที่ใช้ครั้งเดียว ให้ใส่ {until:'step'} ด้วย
B5. **ไม่ต้องกังวลเรื่องขนาดกรอบ** ระบบจะย่อขยาย box ให้ภาพเต็มกรอบพอดีเอง
    ยกเว้นหน้าที่มีกราฟฟังก์ชัน (functiongraph, curve) — กรณีนั้นระบบจะเคารพ box ที่คุณเลือก
    เพราะ "จะแสดงกราฟช่วงไหน" เป็นการตัดสินใจทางคณิตศาสตร์ของคุณ ให้เลือกช่วงที่เห็นจุดสำคัญครบ
    (จุดตัดแกน จุดยอด เส้นกำกับ) และเผื่อขอบไว้เล็กน้อย
B6. บนหน้าที่มีกระดาน **ห้ามเรียก Shell.canvas()** และห้ามใช้ Shell.arrow ด้วยพิกัดกระดาน
    ถ้าจำเป็นต้องใช้ลูกศรทับกระดาน ให้ใส่ {board:true} แล้วส่งพิกัดกระดานได้ตามปกติ

### ตัวอย่างสั้น ๆ (กระดาน)
var b = Shell.board({box:[-5, 9, 10, -3], grid:true}), C = Shell.C;
Shell.setup('จุดศูนย์กลางวงกลมล้อมรอบต้องห่างจากจุดยอดทั้งสามเท่ากัน จึงอยู่บนเส้นแบ่งครึ่งตั้งฉากของทุกด้าน');
var A = b.create('point', [-2, 1]), B = b.create('point', [6, 1]), Cp = b.create('point', [1, 6]);
var tri = b.create('polygon', [A, B, Cp]);
var s1 = Shell.step('วางจุดยอดทั้งสามและลากสามเหลี่ยม $ABC$', {why:'ต้องเห็นรูปก่อนจึงเลือกด้านที่จะสร้างเส้นแบ่งครึ่งตั้งฉากได้'});
Shell.on(s1, A, B, Cp, tri);
Shell.tag(s1, A, 'A(-2, 1)', {role:'given'});
var pb1 = b.create('perpendicularbisector', [A, B], {strokeColor:C.work, dash:2});
var pb2 = b.create('perpendicularbisector', [B, Cp], {strokeColor:C.work, dash:2});
var s2 = Shell.step('สร้างเส้นแบ่งครึ่งตั้งฉากของด้าน $AB$ และ $BC$', {why:'ทุกจุดบนเส้นนี้ห่างจากปลายทั้งสองของด้านเท่ากัน', uses:[1]});
Shell.on(s2, pb1, pb2);
var O = b.create('intersection', [pb1, pb2, 0], {strokeColor:C.answer, fillColor:C.answer, size:5});
var s3 = Shell.step('จุดตัดคือจุดศูนย์กลาง $O$', {why:'อยู่บนเส้นแบ่งครึ่งตั้งฉากทั้งสองพร้อมกัน จึงห่างจากจุดยอดทั้งสามเท่ากัน', uses:[2]});
Shell.on(s3, O);
Shell.tag(s3, O, 'O(2, 2)', {role:'answer'});

## กติกาการอธิบาย (ส่วนที่นักเรียนต้อง "เข้าใจ" ไม่ใช่แค่ "ทำตาม")
A. **Shell.setup()** ใส่เสมอถ้ามีการ "เลือก" ที่ไม่ชัดเจนในตัวเอง เช่น เลือกแกนอ้างอิง เลือกวิธี
   บอกว่าทำไมถึงเลือกแบบนั้น และวิธีนี้ใช้กับโจทย์แบบไหนได้อีก
B. **Shell.group()** ตั้งชื่อกลุ่มขั้นตอนตามชื่อ "วิธี" ที่ใช้จริง เช่น 'สร้างแผนภาพวัตถุอิสระ',
   'วิธีเขียนรังสีสองเส้น', 'ใช้กฎข้อสองของนิวตัน' — นักเรียนจะได้จำวิธีไปใช้กับข้ออื่นได้
C. **why — กฎสำคัญ**: ขั้นใดที่ "สร้างตัวเลขใหม่" ที่ไม่ได้มาจากโจทย์โดยตรงและไม่ได้อ้าง uses
   ขั้นนั้น **ต้องมี why** ระบบตรวจอัตโนมัติ ถ้าไม่มีจะถูกส่งเข้าคิวให้ครูตรวจ
   - why ที่ดี: อธิบาย "ทำไมต้องใช้กฎนี้ตรงนี้" เช่น
     'พื้นดันวัตถุตั้งฉากกับผิวเสมอ จึงต้องแตกแรงในแนวตั้งฉากก่อนหาแรงเสียดทาน'
   - why ที่แย่ (ห้ามเขียน): 'เพราะเป็นสูตร', 'เพราะกฎของนิวตันบอกไว้' — พูดซ้ำว่ามีกฎ ไม่ได้บอกว่าทำไมใช้ได้
   - ขั้นที่แค่วาดรูปหรือคำนวณต่อเนื่องตรง ๆ **ไม่ต้องมี why**
D. **uses** ใส่ทุกครั้งที่หยิบตัวเลขจากขั้นก่อนหน้ามาใช้ เพื่อให้นักเรียนย้อนดูได้ว่าเลขนั้นมาจากไหน
E. **sanity** ใน Shell.answer ต้องมีเสมอ: ตรวจว่าคำตอบสมเหตุสมผลไหม เทียบกับกรณีขีดจำกัดหรือขอบเขต
   เช่น 'น้อยกว่า $g\sin30^\circ = 5$ เพราะแรงเสียดทานต้านการไถล'

## กติกาการใช้
1. เรียงลำดับ: Shell.page(...) → var g = Shell.canvas() → Shell.setup(...) → Shell.group(...)
   → Shell.step(...) หลายครั้ง → Shell.answer(...) → Shell.done()
2. **กติกาข้อความและ LaTeX (อ่านให้ครบ — ผิดข้อนี้แล้วนักเรียนจะเห็นโค้ดดิบบนหน้าจอ)**

   2.1 ทุกอย่างที่เป็น "คณิตศาสตร์" ต้องคร่อมด้วย $...$ เสมอ เช่น 'หาแรง $W = mg = 50$ N'
       ระบบเรนเดอร์ด้วย KaTeX ให้เอง ใช้ได้ใน Shell.step, Shell.answer, Shell.page,
       Shell.setup, Shell.label, why และ sanity

   2.2 **คำสั่ง LaTeX ทุกตัวต้องอยู่ใน $...$ เท่านั้น** ถ้าเขียนนอก $...$ จะโผล่เป็นตัวอักษรดิบ
       เช่น ผู้ใช้จะเห็นคำว่า \textbf{...} หรือ \sum ตรง ๆ บนหน้าจอ
       ผิด : 'ขั้นตอน \textbf{ก่อนชน}'
       ผิด : 'ผลรวม \sum F = ma'
       ถูก : 'ขั้นตอน <b>ก่อนชน</b>'
       ถูก : 'ผลรวม $\sum F = ma$'

   2.3 **ห้ามใส่ภาษาไทยไว้ใน LaTeX เด็ดขาด** — KaTeX ไม่มีฟอนต์ไทยในโหมดคณิตศาสตร์
       ตัวอักษรไทยจะหายไปหรือกลายเป็นกล่องว่าง
       ห้ามใช้ \text{...}, \textbf{...}, \mathrm{...}, \operatorname{...} กับข้อความไทย
       ผิด : '$M_{\text{ทวน}} = 800$'      ผิด : '$v = 2\text{ m/s (ไปทางขวา)}$'
       ถูก : 'โมเมนต์ทวนเข็ม $M = 800$ N·m'
       ถูก : '$v = 2$ m/s (ไปทางขวา)'
       หลักง่าย ๆ: **ภาษาไทยอยู่นอก $...$ เสมอ ตัวเลขและสัญลักษณ์อยู่ใน $...$**

   2.4 หน่วยให้เขียนนอก $...$ เป็นข้อความธรรมดา เช่น '$a = 3.27$ m/s²' ไม่ใช่ '$a = 3.27\ \mathrm{m/s^2}$'
       (เขียนแบบหลังก็ได้ถ้าเป็นอักษรละตินล้วน แต่แบบแรกอ่านง่ายกว่าและพลาดยากกว่า)

   2.5 ตัวหนา/ตัวเอียงในข้อความไทย ให้ใช้ HTML: <b>...</b> และ <i>...</i>
       ขึ้นบรรทัดใหม่ใช้ <br> ไม่ใช่ \n

   2.6 อย่าใส่หมายเลขข้อไว้ต้นข้อความของ Shell.step (เช่น '1. ...') ระบบใส่เลขลำดับให้อยู่แล้ว

   ระบบมีตัวตรวจอัตโนมัติ: ถ้าพบคำสั่งขึ้นต้นด้วย \ หลงเหลือบนหน้าจอ หรือพบภาษาไทยใน \text{...}
   หน้านั้นจะถูกส่งเข้าคิวให้ครูตรวจ
3. **สีมีแค่ 5 สี และหนึ่งสี = หนึ่งความหมาย** ใช้จาก Shell.C เท่านั้น ห้ามใส่สีอื่น:
   given = ค่าที่โจทย์ให้มา, work = ค่าที่คำนวณระหว่างทาง, answer = คำตอบสุดท้ายเท่านั้น,
   note = เส้นแกน เส้นร่าง เส้นช่วย, warn = คำเตือน
4. **ป้ายกำกับทุกอันต้องสร้างด้วย Shell.label เท่านั้น ห้ามสร้าง <text> เอง**
   และต้องใส่ anchor เป็นจุดที่ป้ายอธิบายถึง ระบบจะจัดไม่ให้ทับกัน
4.1 **อายุของป้าย — กฎสำคัญที่สุดในการกันตัวหนังสือทับกัน**
   ป้ายที่ค้างอยู่ทุกอันจนจบ จะทำให้ภาพรกและตัวหนังสือทับกัน ให้คิดเสมอว่า
   "ป้ายนี้ยังจำเป็นในขั้นถัดไปไหม" ถ้าไม่จำเป็น ให้ใส่ until:'step'
   - ค่าที่คำนวณระหว่างทาง (เช่น $W_\perp = 43.3$ N) → until:'step'
   - คำอธิบายวิธีทำ (เช่น "รังสีที่ 2: ผ่านจุดศูนย์กลาง") → until:'step'
   - ชื่อวัตถุหลักและแกนอ้างอิง (เช่น "เลนส์นูน", "แกนมุขสำคัญ", ชื่อจุด F) → until:'end'
   - คำตอบสุดท้าย → until:'end'
   เป้าหมาย: **ในแต่ละขั้นตอน ควรมีป้ายบนภาพไม่เกิน 6 อัน**
4.2 ข้อความบนป้ายให้สั้นที่สุด ใช้สัญลักษณ์แทนประโยค เช่น '$N = 43.3$ N'
   ไม่ใช่ 'แรงปฏิกิริยาตั้งฉากจากพื้น มีค่าเท่ากับ 43.3 นิวตัน'
   คำอธิบายยาว ๆ ให้ไปอยู่ในข้อความของ Shell.step แทน (มีที่ว่างเยอะกว่า)
5. วาดในพิกัด 0..960 (กว้าง) และ 0..540 (สูง) ให้ภาพกินพื้นที่กรอบอย่างน้อย 70%
6. ประกาศ "มาตราส่วน" เป็นตัวแปร JS ก่อนวาด เช่น var PX_PER_N = 2.4;
   ความยาวลูกศรทุกเส้นต้องคำนวณจากตัวแปรนั้น ลูกศรยาวเท่าไรต้องตรงกับตัวเลขบนป้ายเสมอ
   (ระบบจะตรวจข้อนี้อัตโนมัติและรายงานถ้าไม่ตรง)
7. **ลูกศรทุกเส้นต้องสร้างด้วย Shell.arrow เท่านั้น** และใส่ value กับ unit ทุกครั้ง
   ห้ามสร้าง <marker> หรือกำหนด marker-end เอง
8. วัตถุที่ "วางอยู่บน" พื้นผิว ต้องสัมผัสพื้นผิวพอดี ห้ามลอยและห้ามจม
9. ห้ามโหลดไฟล์จากอินเทอร์เน็ต ใช้เฉพาะไฟล์ใน ./lib/ ที่ระบุไว้ข้างบน
10. **ถ้าโจทย์ระบุ "ระดับชั้น:" มาให้ ต้องส่งค่านั้นต่อไปยัง Shell.page ตรง ๆ**
    เช่น ได้รับ "ระดับชั้น: ม.4" → Shell.page({title:..., problem:..., level:'ม.4'})
    ค่านี้มาจากครูผู้ตั้งโจทย์ ไม่ใช่สิ่งที่คุณประเมินเอง จึงห้ามแก้ไขและห้ามตีความใหม่
    **ถ้าโจทย์ไม่ได้ระบุมา ห้ามเดาเอง** ให้ละ level ทิ้งไปเลย (ระบบจะไม่แสดงอะไร)
    เหตุผล: ระดับชั้นที่เดาเอาเองแล้วแสดงบนหน้าจอ ทำให้ครูเข้าใจผิดว่าระบบตรวจสอบมาแล้ว

## ตัวอย่างสั้น ๆ
var SVGNS = 'http://www.w3.org/2000/svg';
Shell.page({title:'แรงบนพื้นเอียง', problem:'กล่อง 5 kg บนพื้นเอียง $30^\circ$ หาความเร่ง'});
var g = Shell.canvas(), C = Shell.C;
var PX_PER_N = 2.4;
var s1 = Shell.step('น้ำหนักของกล่อง $W = mg = 50$ N');
Shell.arrow(s1, 400, 200, 400, 200 + 50*PX_PER_N,
            {role:'given', label:'$W = 50$ N', value:50, unit:'N', until:'end'});
var s2 = Shell.step('แตกแรงตามแนวพื้นเอียง $W_\\parallel = 25$ N');
Shell.arrow(s2, 400, 200, 400 + 25*PX_PER_N, 200,
            {role:'work', label:'$W_\\parallel = 25$ N', value:25, unit:'N', until:'step'});
Shell.answer('ความเร่งของกล่อง', '$a = 3.27\\ \\mathrm{m/s^2}$');
Shell.done();
